# 💕 ربات جرأت حقیقت + سنگ کاغذ قیچی

ربات تلگرامی تماماً دکمه‌ای، برای پیوی و گروه.

- 💗🎀 جرأت/حقیقت با ۴ دسته (عاشقانه، دوستانه، احساسی، مثبت ۱۸) و **۷۰+ سوال آماده**
- 🎯 **بازی نوبتی گروهی**: هر نفر نوبتی حقیقت یا جرات می‌گیره و بقیه انجامش رو تأیید می‌کنن
- ✊✋✌️ سنگ کاغذ قیچی (دو نفره یا با ربات) با امتیاز، آمار برد/باخت و لول‌های عاشقانه
- 🔁 سوال تکراری نمیاد، تا همه‌ی سوال‌های اون دسته دیده بشن
- 🛠 پنل ادمین: افزودن (بدون تکراری)، حذف، آمار و **بکاپ دیتابیس** فقط با دکمه

## 📁 محتویات

| فایل | کار |
|---|---|
| `bot.py` | خود ربات |
| `config.py` | توکن و آیدی ادمین (اینجا رو پر کن) |
| `requirements.txt` | کتابخونه‌های لازم |
| `install.sh` | نصب خودکار پیش‌نیازها |
| `run.sh` | اجرای ربات (با راه‌اندازی مجدد خودکار) |
| `RAILWAY.md` | 🚂 راهنمای اجرا روی Railway |
| `Procfile` ، `railway.json` ، `.python-version` | تنظیمات Railway (دست نزن) |

پیش‌نیاز: **پایتون ۳.۸ یا بالاتر** + کتابخونه‌ی `pyTelegramBotAPI` (نصبش با `install.sh` خودکاره). اینترنت لازمه.

> ☁️ می‌خوای روی Railway اجرا کنی؟ برو سراغ **`RAILWAY.md`**.

## 🚀 راه‌اندازی روی Termux

```bash
pkg update -y && pkg install -y unzip
unzip TruthDareBot.zip
cd TruthDareBot
bash install.sh
nano config.py        # توکن و آیدی ادمین رو بذار (ذخیره: Ctrl+X ، Y ، Enter)
bash run.sh
```

لینوکس / مک / ویندوز هم همینه (نصب دستی: `pip install -r requirements.txt` و بعد `python bot.py`).

## 🤖 ساخت ربات و گرفتن اطلاعات

1. تو تلگرام برو @BotFather ← `/newbot` ← اسم و یوزرنیم بده ← **توکن** رو کپی کن و بذار تو `config.py`.
2. آیدی عددی خودت (و پارتنرت) رو از @userinfobot بگیر و بذار تو `ADMINS` داخل `config.py`.
3. **برای کار تو گروه (مهم):** تو @BotFather بزن `/setprivacy` ← ربات رو انتخاب کن ← **Disable**.
   بعدش ربات رو یه بار از گروه دربیار و دوباره اضافه کن. (یا ربات رو تو گروه ادمین کن.)

## 🎮 طرز استفاده

**پیوی:** ربات یه کیبورد ثابت پایین صفحه می‌ذاره (حقیقت، جرات، سنگ کاغذ قیچی، امتیاز، جدول). هر پیامی هم بفرستی منو باز می‌شه.

**سوال:** دسته رو بزن ← همون لحظه سوال میاد. زیرش:
`➡️ بعدی` ، `💗 حقیقت / 🎀 جرات` (جابه‌جایی سریع) ، `🎯 انتخاب دستی` (صفحه‌ی سوال‌ها) ، `🗂 دسته‌ها`

**گروه** (بدون کامند، فقط بنویس):

| بنویس | چی می‌شه |
|---|---|
| `سوال` یا `حقیقت` / `جرات` | منوی دسته‌ها؛ بعد سوال رندوم با دکمه‌ی بعدی یا انتخاب دستی |
| `نوبتی` | 🎯 بازی نوبتی (پایین‌تر توضیح داده شده) |
| `سنگ کاغذ قیچی` | حریف با «من بازی می‌کنم» وارد می‌شه، یا «با ربات» |
| `امتیاز` | امتیاز و لول خودت (روی پیام کسی ریپلای کنی، امتیاز اون) |
| `جدول` | ۱۰ نفر برتر |
| `بازی` یا `منو` | منوی اصلی |
| `راهنما` | راهنمای کوتاه |

### 🎯 بازی نوبتی
1. تو گروه بنویس `نوبتی` ← دسته رو انتخاب کن.
2. بقیه «من هم هستم» رو می‌زنن (حداقل ۲ نفر، حداکثر ۸) ← «شروع».
3. نوبت هر نفر: خودش حقیقت / جرات / رندوم رو می‌زنه و سوال میاد.
4. **بقیه** با «✅ انجام شد» تأیید می‌کنن (خودش نمی‌تونه تأیید کنه) و ۱ امتیاز می‌گیره. «⏭ رد کردم» بدون امتیاز نوبت رو می‌بره جلو، «🔄 یکی دیگه» سوال رو عوض می‌کنه.
5. «🛑 پایان بازی» خلاصه‌ی امتیازهای اون دور رو نشون می‌ده.

**پنل ادمین** (فقط پیوی ربات، فقط برای ادمین‌ها): افزودن سوال (چند سوال؟ هر کدوم تو یه خط؛ تکراری‌ها خودکار رد می‌شن)، لیست و حذف، 📊 آمار، 💾 بکاپ دیتابیس (فایل td.db برات فرستاده می‌شه).

## ⭐ امتیاز و لول

- هر برد در سنگ کاغذ قیچی = **۳ امتیاز**، هر حقیقت/جرات تأییدشده در بازی نوبتی = **۱ امتیاز** (همه تو دیتابیس ذخیره می‌شن؛ آمار برد/مساوی/باخت هم ثبت می‌شه).
- لول ۱ تا ۲: ۱۰۰ امتیاز، لول ۲ تا ۳: ۲۰۰، لول ۳ تا ۴: ۳۰۰ و همینطور بالا.
- هر لول یه متن عاشقانه‌ی دوطرفه داره.

تنظیمات بالای `bot.py`: `WIN_POINTS` (امتیاز هر برد)، `DONE_POINTS` (امتیاز بازی نوبتی؛ ۰ = بدون امتیاز)، `LEVEL_STEP` (پله‌ی لول)، `LEVELS` (متن لول‌ها)، `PER` (تعداد سوال هر صفحه).

## 💾 دیتابیس

فایل `td.db` کنار `bot.py` ساخته می‌شه و سوال‌ها، امتیازها و تأیید ۱۸+ تو اونه.
برای بکاپ، همین فایل رو کپی کن. برای شروع از صفر، پاکش کن.

## 🛠 مشکل‌یابی

- **ربات تو گروه جواب نمی‌ده:** `/setprivacy` رو Disable نکردی، یا بعدش ربات رو از گروه در نیاوردی و دوباره اضافه نکردی.
- **`config.py` / توکن:** پیام خطا می‌ده؛ توکن باید شکل `123456:ABC...` باشه.
- **سوال‌های آماده‌ی جدید:** اگه از نسخه‌ی قبل آپدیت کردی، سوال‌های جدید بار اول خودشون اضافه می‌شن (بدون پاک شدن چیزی).
- **پنل ادمین نیست:** آیدی عددیت (نه یوزرنیم) باید تو `ADMINS` باشه، و پنل فقط تو پیوی ربات دیده می‌شه.
- **اجرا تو پس‌زمینه (Termux):** `run.sh` خودش `termux-wake-lock` می‌زنه. برای بستن ترمینال، از `tmux` استفاده کن:
  `pkg install tmux` ← `tmux new -s bot` ← `bash run.sh` ← جدا شدن: `Ctrl+B` بعد `D`.
